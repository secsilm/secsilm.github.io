数据与隐私说明

默认匿名请求，额度通常为每个 IP 每小时 60 次，每次最多读取 100 个收藏。大量收藏建议使用自己的 Token。请求失败或取消时不会覆盖上次完整结果。

只缓存最后一次查询的公开仓库，1 小时内可复用；缓存仅在本机浏览器中保存，可随时清除。Token 不写入缓存或导出文件。GitHub 返回的仓库未关闭事项数包含 Issue 和 PR；桑基图需要 Token 分别读取两项数量，不能使用合计数推断。已加载的收藏可直接补充详情，无需重新抓取列表。

图表保留原项目的时间散点图、作者／语言与主题柱状图及桑基图。时间图覆盖完整历史，按 UTC 的日／月／年统计，可拖动缩放；语言排行排除未标注语言。桑基图取收藏仓库数最多的 3 位作者，同数按未关闭事项数排序，流宽表示未关闭的 Issue / PR 数量；零事项仓库不绘制流线。主题最多统计每个仓库返回的前 20 个。此工具用于浏览和分析，不修改收藏。源自 github-star-manager ↗。GitHub 请求限额说明 ↗
